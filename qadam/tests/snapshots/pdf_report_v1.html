0  Tayyorgarlik

1 hafta • 1-2 soat • Rol: Tadqiqotchi

To'siq va yechim:

  • Excel'dan boshqa bilmayman → SQL va visualization'dan boshlash
  • Statistika qiyin → Boshlang'ich daraja yetarli

Keyingi stage'ga shart:

  • Excel chuqur
  • SQL nima tushunaman
  • Kaggle akkaunt

Konikmalar: Excel advanced, SQL basics, Kaggle

1  Asosiy vositalar

4 hafta • 2 soat • Rol: O'rganuvchi

Har kun nima qilish:

  • 30 daqiqa: Excel formula + pivot
  • 60 daqiqa: SQL query yozish
  • 30 daqiqa: Dataset bilan amaliyot

To'siq va yechim:

  • SQL chalkash → SELECT → JOIN tartibida
  • Katta dataset qo'rqitadi → 100 qatordan boshlash

Keyingi stage'ga shart:

  • Excel: pivot, VLOOKUP, chart
  • SQL: SELECT, JOIN, GROUP BY, HAVING
  • 10+ SQL query mashqi
  • Kaggle'da 2-3 dataset tahlil

Konikmalar: Excel, SQL asoslari, Data thinking

2  Vizualizatsiya

6 hafta • 2-3 soat • Rol: Amaliyotchi

Har kun nima qilish:

  • 60 daqiqa: Tableau yoki Power BI mashqi
  • 60 daqiqa: Statistik tushunchalar
  • 60 daqiqa: Dashboard loyiha

To'siq va yechim:

  • Tableau pullik → Power BI yoki Google Data Studio (bepul)
  • Statistika tushunmayman → Mean, median, korrelyatsiya yetarli

Keyingi stage'ga shart:

  • Tableau yoki Power BI'da 3+ dashboard
  • Statistika asoslari
  • Korrelyatsiya, distribution tahlil
  • Business case study

Konikmalar: Tableau, Power BI, Statistika, Business sense

3  Portfolio loyihalar

6 hafta • 3 soat • Rol: Builder

Har kun nima qilish:

  • 120 daqiqa: Loyiha bilan ishlash

Keyingi stage'ga shart:

  • 3-4 portfolio loyiha (GitHub + Tableau Public)
  • Python pandas asoslari
  • Case study yozilgan
  • Business tushuncha

Konikmalar: Python pandas, Storytelling, Portfolio

#2 Foundation Programming

Dasturlash

 Ma'lumot yetarli
Foundation Programming — Roadmap

Nega bu yo'nalish ko'rsatildi

Dasturlash asoslari — har qanday IT yo'nalishga kirish eshigi. Bu bosqich sizga mantiqiy fikrlash, muammoni bo'laklarga bo'lish va kod yozish tajribasini beradi.

A NUQTA — Hozirgi holatingiz

To'siqlar va yechim

  • [SOFT] device — Noutbuk topish yollari — grantlar, kutubxona, ijaraga olish
  • [SOFT] time — Haftalik jadval tuzish, vaqt ajratish

YO'L — 25 hafta (5 stage)

0  Yo'nalishni aniqlash

1 hafta • 1-2 soat • Rol: Tadqiqotchi

Har kun nima qilish:

  • 30 daqiqa: Python yoki JS haqida video
  • 30 daqiqa: VS Code o'rnatish va sozlash
  • 30 daqiqa: Birinchi 'Hello World'
  • 30 daqiqa: GitHub akkaunt ochish

To'siq va yechim:

  • Noutbuk yo'q → Kutubxona, do'st, ijaraga olish, grantlar
  • Qaysi tildan boshlashni bilmayman → Python yoki JavaScript — ikkalasi ham mos
  • Qo'rquv: 'Men qila olamanmi?' → Har kuni 30 daqiqa kod yozish — 7 kunda o'tadi

Keyingi stage'ga shart:

  • VS Code + Git o'rnatilgan
  • Birinchi 'Hello World' ishga tushdi
  • GitHub akkaunt mavjud
  • Kuniga 1 soat o'rganish odat

Konikmalar: VS Code muhiti, Git asoslari, Terminal asoslari

1  Sintaksis asoslari

4 hafta • 1-2 soat • Rol: O'rganuvchi

Har kun nima qilish:

  • 20 daqiqa: Yangi tushunchani o'rganish
  • 40 daqiqa: Kod yozish mashqi
  • 20 daqiqa: Xatolarni tuzatish
  • 40 daqiqa: Amaliy mini-loyiha

To'siq va yechim:

  • Ingliz tili past → O'zbek/rus tilidagi kurslar bor
  • Vaqt kam → Ertalab 1 soat yoki kechqurun 1 soat
  • Motivatsiya tushadi → Har kuni amaliyot — progress ko'rinadi

Keyingi stage'ga shart:

  • Ozgaruvchilar, shartlar (if/else), tsikllar (for/while) tushunasiz
  • Funksiyalar yozishni bilasiz
  • Massiv va obyektlar bilan ishlay olasiz
  • 20+ ta kichik mashq bajarildi

Konikmalar: Sintaksis, Mantiqiy fikrlash, Debugging

2  Muammo hal qilish

8 hafta • 2 soat • Rol: Amaliyotchi

Har kun nima qilish:

  • 30 daqiqa: Yangi algoritm o'rganish
  • 60 daqiqa: 1-2 masala yechish (LeetCode Easy)
  • 30 daqiqa: Kodni GitHub'ga yuklash

To'siq va yechim:

  • Murakkab masalalar qo'rqitadi → Easy darajadan boshla, keyin Medium
  • Vaqt kam → Kuniga 1 masala — 8 haftada 56 masala
  • Algoritm bilmayman → Har kuni 1 yangi algoritm o'rganish

Keyingi stage'ga shart:

  • 50+ LeetCode Easy masala yechildi
  • Asosiy algoritmlar: sort, search, hash
  • Ma'lumotlar tuzilmasi: array, object, set
  • Git bilan ishlashni bilasiz

Konikmalar: Algoritmik fikrlash, Git, Problem solving

3  Kichik loyihalar

8 hafta • 2-3 soat • Rol: Builder

Har kun nima qilish:

  • 30 daqiqa: Loyiha rejasini o'ylash
  • 120 daqiqa: Kod yozish
  • 30 daqiqa: GitHub'ga push

To'siq va yechim:

  • Loyiha g'oyasi yo'q → Tutorial loyihalardan boshlash
  • Mukammal bo'lmasa qo'rqaman → MVP tushunchasi — 20% funksiya, 80% qiymat
  • Vaqt kam → Haftada 1 loyiha — 8 haftada 8 loyiha

Keyingi stage'ga shart:

  • 3-5 ta loyiha GitHub'da
  • Har birida README bor
  • Kamida 2 tasi live (deploy)
  • Kod review qabul qiladi

Konikmalar: Loyiha boshqaruvi, Deploy, README, Git workflow

4  Yo'nalish tanlash

4 hafta • 2-3 soat • Rol: Candidate

Har kun nima qilish:

  • 60 daqiqa: Yo'nalish bo'yicha chuqur bilim
  • 60 daqiqa: Portfolio yaxshilash
  • 60 daqiqa: Junior vakansiyalarga ariza

To'siq va yechim:

  • Ishonchsizlik → Portfolio va GitHub ko'rsatish
  • Reject qo'rquvi → 10 ta ariza → 1 offer — normal
  • Texnik suhbatga tayyor emasman → Mock interview mashqi

Keyingi stage'ga shart:

  • Yo'nalish tanlandi
  • Portfolio 4+ loyiha
  • LinkedIn profili to'ldirilgan
  • 10+ ariza yuborilgan
  • 1+ texnik suhbat o'tkazilgan

Konikmalar: Texnik suhbat, Portfolio, Networking

B NUQTA — Erishishingiz mumkin

  • Junior dasturchi lavozimiga ariza berish imkoniyati
  • Keyingi yo'nalish (Frontend/Backend/Mobile) tanlash imkoniyati
  • GitHub'da 3-5 ta loyiha
  • Texnik suhbatga tayyorlik

Keyingi qadam: Yo'nalish tanlash (Frontend/Backend/Mobile) → Stage 5

Birinchi 3 qadam — bugun boshlang

  1. VS Code va Python'ni o'rnatish (bugun, 30 daqiqa)
  2. Birinchi 'Hello World' dasturini yozish va ishga tushirish (bugun, 15 daqiqa)
  3. GitHub akkaunt ochish va birinchi repo yaratish (bugun, 15 daqiqa)

30 kunlik kalendar

1-hafta: Vositalar + sintaksis

  • Du: VS Code + Python ornatish, Hello World
  • Se: Ozgaruvchilar, print, input
  • Ch: Shartlar (if/else), mantiqiy operatorlar
  • Pa: Tsikllar (for/while)
  • Ju: Funksiyalar — birinchi yozish
  • Sh: Amaliyot: kalkulyator
  • Ya: Dam olish

2-hafta: Malumot tuzilmalari

  • Du: List va tuple
  • Se: Dictionary va set
  • Ch: String metodlari
  • Pa: Xatoliklarni tutish (try/except)
  • Ju: Modul va paket
  • Sh: Amaliyot: todo list (CLI)
  • Ya: Dam olish

3-hafta: Fayllar va OOP

  • Du: Faylni o'qish/yozish
  • Se: JSON bilan ishlash
  • Ch: OOP: class va object
  • Pa: OOP: metod va inheritance
  • Ju: Amaliyot: weather app (API)
  • Sh: Git chuqur: branch, merge
  • Ya: Dam olish

4-hafta: Mini loyiha + portfolio

  • Du: Loyiha rejasini tuzish
  • Se: Kod yozishni boshlash
  • Ch: Kod davom etish
  • Pa: Test va debug
  • Ju: README yozish
  • Sh: GitHub'ga push + deploy
  • Ya: Portfolio'ga qo'shish

Muhim nuqtalar

  • 1h — Birinchi kod ishga tushdi
  • 4h — 50+ qator kod yozildi
  • 8h — Birinchi mini-loyiha tayyor
  • 16h — 3+ loyiha GitHub'da
  • 24h — Birinchi texnik suhbat
